# M8b — Spanish → English pack

> Executed with superpowers:subagent-driven-development. TDD; data scripts tested on fixtures in Node, packs and dictionary in Node, Settings in Vitest Browser Mode, the built extension with Playwright E2E.

**Goal:** a learner of Spanish whose language is English can use Lingo: Spanish words and phrases are segmented, lemmatized, ranked, highlighted and looked up with English meanings and IPA. The pack plugs in beside en → ja: the English pack, the en → ja dictionary and their files stay as they are.

## Sources
- kaikki Spanish: `data/raw/kaikki-es.jsonl` (1.1 GB, 814,137 entries: 124,625 with a sense that is not `form_of`, 689,512 inflected forms, 22,052 multi-word). Senses have English `glosses`; inflected entries point to their base through `senses[].form_of[].word` (`comiendo` → comer, `casas` → casa / casar). `sounds[]` has an untagged phonemic `/…/` IPA first (`/koˈmeɾ/`)
- Frequency: Wiktionary "Frequency lists/Spanish/Mixed 730K" (Leipzig corpora: 2021 Wikipedia and 2022 news, CC BY-SA). The main page holds ranks 1–10,000 as sections `==1-1000==` … with one `[[word#Spanish|word]]` per line in rank order; subpages `/10001-20000` … hold the rest in the same format. Entries are case-sensitive and may contain spaces ("El lugar"). Fetched via the MediaWiki API (`action=parse&prop=wikitext`) like `frequency.mjs`, cached in `data/raw/freq-es/`

## Output files (`public/packs/es/`, `public/packs/es-en/`; same conventions as en: sorted keys, `stringifyPack`, every file < 4 MB)
| File | Shape | Content |
|---|---|---|
| `es/freq.json` | `string[]` | base forms in rank order: forms from the frequency list (lowercased, single words matching `^\p{L}+$`u) mapped to their bases; a base keeps its best rank. Top 30,000 bases |
| `es/vocab.json` | `string[]` | the vocabulary: bases that have an es-en dictionary entry and are reached from the first N forms of the frequency list (N chosen so the vocabulary is 30–50k words and the files fit; start with N = 100,000 forms) |
| `es/lemmas.json` | `{ [form]: string \| string[] }` | form → base(s) for forms in the first N frequency-list forms whose kaikki form-of entries point to vocabulary bases (form ≠ base). Forms that are themselves vocabulary words keep their bases too (Spanish "casas" is both) |
| `es/ipa.json` | `{ [word]: string }` | first phonemic `/…/` IPA of each vocabulary word |
| `es/phrases.json` | `string[]` | multi-word kaikki entries whose words are all in the vocabulary, with a usable sense tagged `idiomatic` or pos `phrase` / `prep_phrase`, and at least one word outside the top 1,000 (same usable-sense rule as `scripts/data/phrases.mjs`); left out if the size budget is tight |
| `es-en/dict-<n>.json` + `index.json` | `{ [term]: [short, [pos, text][]] }` (the `DefsPack` shape) | English meanings of vocabulary words and phrases: up to 6 usable senses per term across its entries (pos from `posLabel`), `text` = the sense's last gloss; `short` = the first sense cut at the first `;`. Sharded with `shardDict` |

Record counts, sizes and the zipped size against phase 1's ~3 MB (now 3.9 MB after M8a) in `docs/status.md`.

## Tasks
1. **Data scripts** `scripts/data/es-frequency.mjs` (fetch + parse the list format above, fixture test) and `scripts/data/es-kaikki.mjs` (stream kaikki-es → lemmas, ipa, pos labels, dictionary, phrases; fixture `scripts/data/fixtures/kaikki-es.jsonl` with comer, comiendo, casa, casas (noun + verb form), hablar/hablo, an entry with only form-of senses, a phrase, a word outside the frequency range), plus a builder that writes the files. Reuse `common.mjs`, `shardDict`, `posLabel`, the usable-sense helpers of `phrases.mjs` (export them rather than copy). `npm run data:es` runs them; `data:build` stays English-only. Run on the real data, tune N, commit the outputs. A test checks that the Spanish builders only write under `es/` and `es-en/`
2. **Runtime**
   - `src/core/packs/load.ts`: packs `es` (`lemmas`, `freq`, `ipa`, `phrases`, `vocab`) and `es-en` (`{ defs: DefsPack }` from shards)
   - `src/core/language-pack.ts`: a generic `createLanguagePack(lang, data)`; `createEnglishPack` becomes a thin call of it (behavior unchanged)
   - `src/core/dictionary.ts`: `createDefsDictionary({ from, to, defs, ipa })` for dictionaries whose senses carry their pos (es → en); no `glossLang` (meanings are in `to`)
   - `src/background/language-resources.ts`: a registry — learning-language packs `{ en, es }` and dictionaries `{ "en-ja", "es-en" }`, each with the packs it loads; unknown languages reject as now. The en / en-ja entries build exactly what they build today
   - Tests: registry (es pack and es-en dictionary build, en-ja unchanged, unknown pair rejects), dictionary, smoke test over the real files ("comiendo" → comer with "to eat", "casas" → casa and casar, IPA of comer, a phrase if present), classifier on a Spanish sentence
3. **Settings and the rest**
   - Settings page (`src/entrypoints/options/SettingsPage.tsx`): learning-language select English / Spanish; native-language select lists only languages with a dictionary for the chosen learning language (en → Japanese, es → English); changing the learning language sets the native language to the first available one in the same `setSettings` call. `language.es` in `src/i18n/locales/en.json`. The level slider copy already names the language ("Treat the 3,000 most common Spanish words as known")
   - The language pair shown in the popup header and word list header, counts and the word list follow the settings (check they are not hard-coded to en/ja)
   - `SPEECH_LANG` (article, video session, word list): `es: "es-ES"` — move the three copies into one shared table
   - `src/ui/lookup/externalDictionaries.ts`: Spanish → English links — Cambridge `spanish-english`, WordReference `esen`, Reverso `spanish-english`, Wiktionary `#Spanish` anchor
   - Check that `storage.sync` encoding (`src/core/sync/`) handles terms of more than one language (ids are `lang:key`); add a test with en and es terms together
   - Tests: Settings Browser Mode (select options and the paired change), external links, E2E: a Spanish article fixture (`e2e/pages/article-es.html`, `lang="es"`) with the learning language set to Spanish shows highlights, a hover card with an English meaning and IPA, and saving works
