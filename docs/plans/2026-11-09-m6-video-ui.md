# M6 — Video UI (YouTube, Netflix)

> Executed with superpowers:subagent-driven-development. TDD: parsers and timing logic with fixtures in Node; components in Vitest Browser Mode; the whole flow with Playwright E2E against fixture pages served on the real site URLs through `context.route` (so the real adapters and content scripts run). Before committing a UI change, compare with `project/Main.dc.html`. Finally, check real YouTube in Playwright Chromium with the extension.

**Goal:** the spec's "Video UI": two columns (video + transcript), the dictionary window, subtitle position (In video / Below video), separate translation switches for the subtitle and the transcript, the green-outlined L button + ^ menu in the player bar, site-first translation, the "Video finished" card, and occurrence recording with timestamps.

## Architecture
| Path | Responsibility |
|---|---|
| `src/core/subtitles/types.ts` | `Cue { startMs, endMs, text }`, `Track { id, lang, kind: "manual" \| "asr", label }` |
| `src/core/subtitles/youtube-json3.ts`, `ttml.ts`, `webvtt.ts` | pure parsers (fixtures in `src/core/subtitles/fixtures/`) |

| `src/content/video/platform.ts` | `PlatformAdapter` interface: `matches(url)`, `videoId()`, `title()`, `video()`, `playerElement()`, `controlsElement()`, `belowVideoElement()`, `sideColumn()` (insertion point), `adShowing()`, `tracks()`, `loadCaptions({ learningLang, nativeLang, translatorAvailable, signal })` → original cues + one translation choice with its cues, `seek(ms)`, `onNavigate(cb)`, `hideSiteCaptions(on)` |

| `src/content/video/youtube.ts` | YouTube adapter in the isolated world: SPA navigation (`yt-navigate-finish`), `#movie_player`, `.ytp-right-controls`, `#below`, `#secondary-inner` before `#related`; reuses the player's own timedtext request (asks the player for the original track when it made none, then restores its caption choice) and fetches the native-language manual track, else `&tlang=<native>`, by editing that URL |
| `src/entrypoints/netflix-main.content.ts` (MAIN world) | hook `JSON.parse` to read `timedtexttracks` from the manifest (TTML/WebVTT URLs per language); expose seek through `netflix.appContext.state.playerApp.getAPI().videoPlayer` |

## Decisions
- Lingo "off for this video" restores the site's own captions and removes our UI except the player-bar group
- Subtitle translations shown are the ones chosen per video; the occurrence's `translation` is the translation shown
- The transcript lives in YouTube's right column (`#secondary`, above recommendations). On Netflix (no side column) the transcript is a panel at the right of the player area and the player is narrowed with a CSS variable; check on real Netflix later (manual)
- Words in subtitles use the same `analyze` spans; New/Known/Learning toggles come from settings; transcript chips change the same settings as the article card
- Subtitles are processed in memory only (Chrome Web Store decision); only sentences of saved words are stored as occurrences
- Fullscreen is phase 2: in fullscreen, phase 1 hides our overlay and lets the site captions show
